# Bruxelles cinema sources

Added on 7 November 2026 under the catalogue city **Bruxelles**, with `Europe/Brussels` screening dates and `fr-BE` metadata lookup language. Film language is left unknown when not supplied; original-language films are not labelled as French. The generic map query already supports new cities using their venue coordinates. Scrapers are automatically discovered by the existing runners and CI matrix.

| Scraper                       | Official programme source and API findings                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `aventureBruxellesCinema.ts`  | [Aventure's complete table](https://www.cinema-aventure.be/catalogue/?view=table). UTick/Infinitix site without an advertised usable public schedule API; use full French date headings, carried through blank subsequent rows, and supplied session ticket links.                                                                                                                                                                                          |
| `palaceBruxellesCinema.ts`    | [Palace](https://www.cinema-palace.be/films/). Advertised WordPress `palace/v1/getListingFilms?lang=fr` returns the film roster as HTML. Separate `minos/v1/films` and `minos/v1/getFilms` APIs require authorization and are not used. Follow French film links with three workers and parse full `datetime` attributes in `#seances`. A forthcoming film without sessions does not create invented showtimes.                                             |
| `galeriesBruxellesCinema.ts`  | [Galeries](https://galeries.be/fr/). Public WordPress posts omit showtimes. The [official booking app](https://bruxellescinemagaleries.cine.boutique/) advertises its CineOffice API host and public application token; discover both at runtime. Join `shows` to `media`, filter venue IDs, exclude school/deleted/cancelled sessions, convert runtime seconds to minutes and preserve explicit offsets. No login or private account credentials are used. |
| `cinematekBruxellesCinema.ts` | [CINEMATEK's complete calendar](https://cinematek.be/programme/calendrier). Craft site without an advertised public schedule API; parse full date groups and times, only Ledoux/Plateau auditoria. Double bills remain one programme; duration is summed only when every film has one. The published calendar also includes past screenings; validation counts upcoming screenings separately.                                                              |
| `novaBruxellesCinema.ts`      | [Nova calendar](https://www.nova-cinema.org/spip.php?page=seances). SPIP site without an advertised public screening API; parse full date headings and individual event times. Exclude talks, concerts and other non-film activities. Compilations remain one programme and do not inherit their first short's metadata.                                                                                                                                    |
| `ritcsBruxellesCinema.ts`     | [Cinema RITCS](https://www.cinemaritcs.be/). WordPress Theatre plugin; public `wp/v2/wp_theatre_prod` exposes productions but omits screening dates. Parse the plugin's complete HTML event listing instead.                                                                                                                                                                                                                                                |
| `vendomeBruxellesCinema.ts`   | [Vendôme timetable](http://www.cinema-vendome.be/les_films/horaires). eZ Publish site without an advertised usable public API. HTTPS fails TLS verification in the checked environment, so use the supported HTTP site. Resolve yearless day/month entries only to a nearby year matching the printed weekday; reject ambiguous/stale dates. Film pages are booking entry points; Billetweb event IDs are not guessed.                                      |
| `ugcBruxellesCinema.ts`       | [UGC De Brouckère](https://www.ugc.be/cinema.html?id=2) and [UGC Toison d'Or](https://www.ugc.be/cinema.html?id=1). Public read-only `showingsCinemaAjaxAction!getShowingsForCinemaPage.action`. Discover every advertised booking date, including advance bookings, then request it with three workers. Filter individual sessions by cinema ID and use their full dates and direct booking IDs. One chain scraper covers both venues.                     |
| `flageyBruxellesCinema.ts`    | [Cineflagey's cinema-only calendar](https://www.flagey.be/en/agenda/cinema). No usable public schedule API advertised. Stateless HTTP loops through the cookie redirect, so use a normal Playwright session and the published `data-event-start` attributes. Follow all `rel=next` pages, rejecting repeated/unexpected targets or truncation. Only `data-production-type=movie` sessions are included.                                                     |

Run `npm run test_scraper -- Bruxelles` without updating Supabase. Initial successful live checks returned Aventure 97 screenings; CINEMATEK 427 (114 upcoming); Galeries 54; Nova 25 (one upcoming); Palace 70; RITCS 19; Vendôme 105; the two UGC venues 579 combined; Cineflagey 79. Counts change as ticket sales and programmes are updated. Representative public programme fixtures are in `tests/fixtures/bruxelles`.

Kinepolis Bruxelles was investigated but returned HTTP 403 access-check pages in both HTTP and a normal browser. Le Stockel's WordPress index has no public film/schedule collection and its current official page renders an empty timetable. Neither is registered as a working scraper.
